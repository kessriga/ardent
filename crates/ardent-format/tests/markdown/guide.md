# Guide

Ardent derives an outline
from each source file.

## Install

- Download the binary.
- Put it on the `PATH`:
  - macOS: `/usr/local/bin`
  - Linux: `~/.local/bin`

  Restart the shell afterwards.
- Run `ardent init`:

  ```sh
  ardent init
  ```
